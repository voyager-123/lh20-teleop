# 纯视觉同步采集

在仓库目录运行 `./lh20-capture`。可选 `--camera 1`。这个独立入口只启动摄像头、同一套左手 swapped 重定向和 CAD 检查，没有运动发送器，不启动 ROS/CAN 驱动。已有 SDK 可保持运行。

每次在 `teleop/data/teleop_study/synced/` 新建目录，保存：

- `camera.avi`：FFV1 无损原始摄像头图像，无界面覆盖文字。
- `frames.jsonl`：帧索引、读取后单调时间、归档后时间、处理完成时间、检测关键点、候选姿态、明确的拒绝原因和通过后的目标。
- `markers.jsonl`：B 遮挡意图开始、E 遮挡已移开、Q 退出；标记包含按键读取时间和最近显示的视频帧索引。
- `metadata.json`：模型与映射摘要、原有滤波参数、采集状态和关闭后的解码帧数校验。

视频按 30 fps 的标称速率封装；实际帧率会因检测、编码和渲染变化。**精确对应应使用 `video_frame_index` 与 JSON 的时间戳，不能把视频播放秒数当真实采集秒数。** `captured_monotonic_ns` 是读取后时间，并非摄像头曝光时间。处理耗时也不等于端到端遥操延迟。

推荐首段采集：前臂支撑、左手自然张开保持不动；先无遮挡保持约 3 秒。窗口获得焦点后按 B，再用另一只手拿纸板从侧面遮住部分左手，约 2 秒后移开并按 E；无遮挡保持约 3 秒。重复三次，按 Q 保存。标记只提供复核线索，实际遮挡开始与结束需看视频。全遮挡期间仍没有独立人手姿态真值。

`rejection_reason` 区分未识别到所选左手、无效关键点、优化失败、输出越界、CAD 自碰撞、量化后检查和映射失败。没有选中左手不等于画面里完全没有手。候选姿态沿用现有优化器及低通滤波，不代表未经滤波的原始优化解。
