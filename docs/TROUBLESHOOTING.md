# 常见问题

| 现象 | 检查 / 操作 |
| --- | --- |
| CAN 接口尚未启动 | `ip -details link show can0`；停止控制会话后按 README 配置为 UP、1 Mbps |
| `RTNETLINK answers: Device or resource busy` | 接口已 UP 时不能直接修改 bitrate；先停止控制，再 down → 配置 → up |
| 找不到 can0 | 检查 USB-CAN 连接、`lsusb`、`ip link`；不是激活 Conda 就能出现 can0 |
| 要求登记左手身份 | 运行 `./scripts/register_hand.sh`；身份保存在本机 `.local.env`，不要提交 |
| 另一台电脑 SDK / 右手节点干扰 | 通过本工程入口启动；会设置本机 ROS 发现范围。已有旧节点需在其所属终端停止 |
| SDK 或控制发布者重复 | 在原 `(lh20_ros2)` SDK / GUI / teleop 终端 Ctrl+C，只保留一个自动遥操会话 |
| 等待物理左手 | 让左手完整入镜、掌部和手指关键点清晰；检查相机编号。识别后自动跟随，无 READY 操作 |
| 跟随速度明显偏慢 | 检查光照、遮挡、CPU 占用；日志中的 `vision_age_ms`、`cad_ms` 可区分视觉和 CAD 耗时。大幅手势也可能受模型速度与反馈领先预算限制 |
| 频繁 `FEEDBACK_MOVED_DURING_CAD_CHECK`、动作一顿一顿 | 旧版会把检查期间的正常运动当成需要重新识别的事件。新版丢弃该条检查结果，直接按最新反馈重新检查；仍不发布未经新路径检查的目标 |
| 某个关节停住但别的能动 | 属于单关节卡滞隔离。往反方向做手势释放；日志保留 held / released 事件，不需要重启整套程序 |
| `CAD_WAITING_FOR_SEPARATING_MOTION` | 当前手势会增加模型接触，改做分离 / 张开的手势；程序保持接收目标 |
| 视觉目标一直变化，整手完全不动 | 查看 `teleop/data/live_hand_*.jsonl`：`execute: true` 但只有 `cad_blocked`、没有 `command` 时，目标未通过 CAD 检查，还没有发到电机。新版本会尝试暂停接触相关手指，并对其余手指的组合路径重新完整检查 |
| `CAD_PARTIAL_FOLLOWING` | 接触相关手指暂停，其余手指通过完整路径检查后继续随动。暂停轴的至多 2 计数反馈波动会在原限速内就地保持；更大偏差不会重设目标。整手路径不再加深或新增接触后自动恢复；不会绕过 CAD 检查 |
| 64 / 128 仍导致退出 | 确认使用本次版本的左手入口；只忽略“精确等于 64 或 128”的 raw 值，其他故障和通信失效仍会停止 |
| 拇指方向不匹配 | 这只手的经验方向配置为 `swapped`，尚未完成逐轴角度标定；新设备需逐轴核对，不能只凭外观判断角度关系 |
| 拇指模型基本正确、实物不准确 | 模型显示视觉目标；检查控制日志 `joint_isolation`、`cad_partial_follow` 以及 `desired` / `target` / `feedback`。2026-10-25 21:39 会话有拇指根部单关节隔离。若稳定执行反馈已追上仍有姿态差异，再核对实物通道、零位、量程及耦合；raw 追上不等于真实角度已标定 |
| 拇指方向基本对，但幅度或姿态有偏差 | 当前使用 `--thumb-profile segments`；2026-10-25 用户实机确认 `palm` 更差，已停止推荐。需对照真人关键点、拇指目标、实际反馈和实物姿态再校准，不能凭模型测试增加增益或换轴 |
| Vector 新版效果需要核对 | 继续使用 `vision vector`。新版补入拇指尖方向，实时读取最新帧并使用速度自适应滤波；观察日志 `vector_thumb_target`、`joint_filter` 和 `timing_ms`，区分检测、求解、CAD 与执行滞后。离线方向误差不是实物精度，仍需实机对照 |
| DexPilot 四指最靠指尖的关节始终弯曲 | 检查视觉目标与实际反馈。初版直接对应手腕原点造成腕到指尖目标偏短；掌部参考对齐与四指骨链长度适配缓解了此问题，但小指仍存在目标超出模型可达范围、两类目标尺寸不一致的问题。使用 `vision vector` 可对照原 Vector；不能把比例适配当作已完成实物标定 |
| Python / numpy / rclpy 导入冲突 | 不要将 ROS 的 PYTHONPATH 复制到视觉环境；使用包装脚本并核对两个环境的 Python 版本 |
| 已经打开 vision，还需 ROS 终端吗 | 不需要。自动会话会启动或复用 SDK；单独读状态时才可另外开 `(lh20_ros2)` 终端 |
| 退出后没有回位 | 设计如此；不自动发送回位动作 |

运行日志位于 `teleop/data/`。公开提问前，先去除设备身份、绝对路径和无关个人内容；不要直接上传整个 data 目录。
