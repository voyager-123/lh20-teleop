# 0.1.0-draft 验证记录

2026-10-22，Ubuntu 24.04 x86_64。记录区分实机反馈、公开副本检查和未完成的验证。

## 使用者实机反馈

- L20-10 / G20 左手、固件 1.0.6、SocketCAN can0 / 1 Mbps。
- 摄像头打开后检测到左手即自动跟随；使用者确认“这版基本没问题，可以作为初稿”。
- 使用者确认拇指需要 `swapped`。保留精确 64 / 128 故障例外及卡滞单关节隔离。
- 这属于基本动作的定性验收，没有测量角度精度、任务成功率或端到端延迟。

## 此公开副本已通过

| 检查 | 结果 |
| --- | --- |
| SDK `colcon build --symlink-install --packages-select linker_hand_ros2_sdk` | 通过 |
| `./lh20-left check`：两个消息包、SDK 导入、随机本机 ROS 话题回环 | 通过；没有构建设备对象或发布控制目标 |
| `teleop/tests` 发布版无硬件回归 | 40 项通过，无跳过 |

| native / swapped 编码和解码 | 只有两个拇指通道交换，其他通道不变；配置摘要不同 |
| 延迟 / 速度 / 卡滞逻辑 | 合成轨迹覆盖快慢电机、250 ms 滞后、旧目标替换、单关节冻结与反向释放 |
| 精确故障例外 | 64、128 可继续；组合码 192 和其他错误、过期反馈仍被拒绝 |
